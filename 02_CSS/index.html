Bài giải Chương 2: 12 bài, từ mục 2.1 đến 2.12 của giáo trình. Mỗi bài gồm yêu cầu, mã nguồn và nhận xét. Các tệp gốc giữ giá trị ban đầu theo đề; phần nhận xét giải thích kết quả khi thử thay đổi.

Bài 1. CSS nội bộ cơ bản

1. Yêu cầu và tệp bài làm

Dùng thẻ style trong head; Arial; nền #f5f5f5; h1 xanh, 32px, căn giữa; h2 darkgreen 24px; p #333 16px.

Mở kết quả Bài 1

2. Mã HTML

<!DOCTYPE html>
<html lang="vi">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Bài 1 - CSS nội bộ cơ bản</title>
<style>
body {
    font-family: Arial, sans-serif;
    background-color: #f5f5f5;
}
h1 {
    color: blue;
    font-size: 32px;
    text-align: center;
}
h2 {
    color: darkgreen;
    font-size: 24px;
}
p {
    color: #333;
    font-size: 16px;
}
</style>
</head>
<body>
<h1>THIẾT KẾ WEB</h1>
<h2>Thông tin môn học</h2>
<p>Môn học cung cấp các kiến thức cơ bản về thiết kế và xây dựng giao diện Web.</p>
<h2>Nội dung thực hành</h2>
<p>Sinh viên thực hành HTML, CSS, JavaScript và Bootstrap.</p>
</body>
</html>

Thao tác và nhận xét

  1. color thay đổi màu chữ của phần tử; không đổi màu nền. Đổi blue thành red làm tiêu đề h1 đỏ.
  2. text-align: left, center, right lần lượt căn nội dung về trái, giữa, phải trong hộp h1.
  3. font-size càng lớn thì chữ càng lớn; ví dụ 20px nhỏ hơn 32px, 40px lớn hơn 32px.

Bài 2. CSS nội tuyến

1. Yêu cầu và tệp bài làm

Chỉ dùng thuộc tính style trên từng thẻ; không dùng thẻ style hay tệp CSS ngoài.

Mở kết quả Bài 2

2. Mã HTML

<!DOCTYPE html>
<html lang="vi">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Bài 2 - CSS nội tuyến</title>

</head>
<body>
<h1 style="color: blue; font-size: 32px; text-align: center;">THIẾT KẾ WEB</h1>
<h2 style="color: darkgreen; font-size: 24px;">Thông tin môn học</h2>
<p style="color: #333; font-size: 16px;">Môn học cung cấp các kiến thức cơ bản về thiết kế và xây dựng giao diện Web.</p>
<h2 style="color: darkgreen; font-size: 24px;">Nội dung thực hành</h2>
<p style="color: #333; font-size: 16px;">Sinh viên thực hành HTML, CSS, JavaScript và Bootstrap.</p>
</body>
</html>

Thao tác và nhận xét

  1. Đổi color: blue thành red: chỉ tiêu đề h1 chuyển sang đỏ.
  2. Đổi text-align: center thành right: nội dung tiêu đề căn phải.
  3. Đổi font-size từ 32px xuống 20px: chữ tiêu đề nhỏ hơn.
  4. Xóa style của h1: trình duyệt dùng quy tắc mặc định hoặc CSS kế thừa còn áp dụng. Trong bài này h1 thường đậm, cỡ 2em và căn trái trong trang tiếng Việt mặc định.

Bài 5. Bộ chọn thẻ, class và id

1. Yêu cầu và tệp bài làm

Dùng CSS ngoài, bộ chọn body, #tieude, .thongbao và .luuy.

Mở kết quả Bài 5

2. Mã HTML

<!DOCTYPE html>
<html lang="vi">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Bài 5 - Bộ chọn thẻ, class và id</title>
<link rel="stylesheet" href="style.css">
</head>
<body>
<h1 id="tieude">THÔNG BÁO ĐĂNG KÝ HỌC PHẦN</h1>
<p class="thongbao"><strong>Thời gian đăng ký:</strong> từ ngày 01/10/2026 đến ngày 10/10/2026.</p>
<p class="thongbao"><em>Sinh viên cần hoàn thành đăng ký trong thời gian quy định.</em></p>
<hr>
<p class="luuy"><strong>Lưu ý:</strong> Sinh viên phải kiểm tra lịch học trước khi đăng ký.</p>
</body>
</html>

3. Mã CSS

body {
    font-family: Arial, sans-serif;
    color: #333;
}
#tieude {
    color: darkblue;
    font-size: 30px;
    text-align: center;
}
.thongbao {
    color: #0066cc;
    font-size: 18px;
}
.luuy {
    color: red;
    font-weight: bold;
}

Thao tác và nhận xét

  1. Đổi color của body chỉ ảnh hưởng chữ kế thừa màu từ body. Các phần tử có màu riêng như #tieude, .thongbao và .luuy giữ màu đã khai báo; trong nội dung mẫu, các khối chữ đều có màu riêng nên không đổi màu thấy được.
  2. Đổi .thongbao sang green: cả 2 đoạn có class="thongbao" đổi sang xanh lá.
  3. Thêm class="luuy" vào đoạn khác: đoạn đó đỏ và đậm. Nếu đoạn đã có class, thêm tên lớp vào danh sách, ví dụ class="thongbao luuy". Với thứ tự CSS hiện tại, .luuy quyết định màu đỏ, .thongbao vẫn cho cỡ chữ 18px.
  4. Đổi #tieude sang text-align: left chỉ căn trái tiêu đề có id="tieude".
  5. class được tái sử dụng trên nhiều phần tử; id phải duy nhất trong một tài liệu. Bộ chọn id có độ ưu tiên cao hơn class khi các điều kiện cascade khác tương đương.

    padding: 20px;
    margin: 0;
}

    padding: 15px;
    margin-bottom: 30px;
}
h2 {
    padding: 10px;
    border-left: 5px solid darkgreen;

p {
    padding: 15px;
    border: 1px solid #ccc;
    margin-bottom: 20px;
    background-color: white;
}

Thao tác và nhận xét

  1. Tăng padding từ 15px lên 30px tạo thêm 15px khoảng trống ở mỗi phía bên trong đường viền.
  2. Tăng border từ 1px lên 5px làm viền dày hơn 4px mỗi phía. Với width: auto, hộp khối vẫn lấp chiều ngang có sẵn, phần nội dung bên trong hẹp lại.
  3. Tăng margin-bottom từ 20px lên 50px làm khoảng cách tới phần tử sau lớn hơn; lề dọc giữa các khối có thể gộp (margin collapse), nên không luôn cộng trực tiếp hai lề.
  4. padding tạo khoảng cách bên trong hộp và nhận màu nền của hộp; margin tạo khoảng cách bên ngoài đường viền, không nhận nền của hộp.
  5. Bỏ border thì padding vẫn có tác dụng, vẫn tạo khoảng trống giữa chữ và mép vùng nền.

Thao tác và nhận xét

  1. content-box: width chỉ tính phần nội dung; border-box: width đã gồm nội dung, padding và border. Tổng chiều rộng nêu dưới đây không tính margin.
  2. contentBox = 500 + 20 × 2 + 5 × 2 = 550px. borderBox = 500px; phần nội dung = 500 − 40 − 10 = 450px.
  3. Đổi contentBox sang border-box: hai hộp đều rộng tổng cộng 500px.
  4. Khôi phục content-box rồi đổi padding chung lên 40px: contentBox rộng 590px; borderBox vẫn rộng 500px, phần nội dung còn 410px. Nếu chỉ sửa padding của contentBox, borderBox không thay đổi.
  5. Với width: 80%, gọi chiều rộng khối chứa là W: contentBox rộng 0.8W + 50px, borderBox rộng 0.8W (giữ padding 20px). Các hộp thay đổi theo chiều rộng cửa sổ.
  6. Thêm max-width: 700px khi đang dùng width: 80%: giới hạn phần content của content-box ở 700px, nên hộp có thể rộng tổng cộng 750px; với border-box, tổng chiều rộng tối đa là 700px. Nếu vẫn width: 500px thì max-width: 700px chưa làm thay đổi kích thước.
  7. Bài giữ đúng width: 500px nên có thể tràn trên màn hình nhỏ; đây là ví dụ đo mô hình hộp, không tự co chiều rộng.
