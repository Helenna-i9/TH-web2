# Bài 7: Màu sắc và phông chữ

## 1. Yêu cầu

Dùng style7.css; định dạng màu nền, màu chữ, font-size, font-weight và line-height theo đề.

## 2. Tệp bài làm

Mở bai7.html bằng trình duyệt. CSS nằm trong style7.css, cùng thư mục HTML.

## 3. Thao tác và nhận xét

1. Đổi nền body sang lightyellow làm nền trang vàng nhạt. Những vùng đã có nền riêng vẫn giữ màu nền riêng.

2. Đổi Arial sang "Times New Roman", serif làm chữ chuyển sang phông có chân nếu phông có sẵn.

3. font-weight: normal làm liên kết bớt đậm so với bold.

4. Với chữ 16px, line-height: 1, 1.6, 2 lần lượt tương ứng chiều cao dòng 16px, 25.6px, 32px. Dòng quá sát khó đọc; tăng chiều cao dòng tạo thêm khoảng cách.

5. Đề có dòng color: #333 ở cuối nav a:hover. Dòng này sẽ ghi đè color: red; bài giải bỏ dòng dư để đúng yêu cầu màu đỏ.

## 4. Cách thử

Sửa một thuộc tính mỗi lần, lưu tệp, tải lại trình duyệt. Sau khi quan sát, khôi phục giá trị ban đầu trước khi thử mục tiếp theo.
