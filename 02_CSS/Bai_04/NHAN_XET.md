# Bài 4: CSS bên ngoài

## 1. Yêu cầu

Làm lại Bài 2 bằng tệp style.css và thẻ link.

## 2. Tệp bài làm

Mở bai4.html bằng trình duyệt. CSS nằm trong style.css, cùng thư mục HTML.

## 3. Thao tác và nhận xét

1. Sửa các thuộc tính color, text-align, font-size của h1 trong style.css; lưu rồi tải lại trang để xem thay đổi như Bài 2.

2. Xóa quy tắc h1 trong style.css để xem kiểu mặc định. Xóa thuộc tính style trên thẻ HTML không làm mất CSS bên ngoài.

3. CSS bên ngoài có thể được nhiều trang cùng liên kết, giúp tái sử dụng và bảo trì. Nếu sai đường dẫn href, trang không nhận được CSS.

## 4. Cách thử

Sửa một thuộc tính mỗi lần, lưu tệp, tải lại trình duyệt. Sau khi quan sát, khôi phục giá trị ban đầu trước khi thử mục tiếp theo.
